# VC Retail Analytics — update for Tyler (2026-10-03)

**Demo:** https://vc.datasharkbi.com/ (Cloudflare Access, email code; `operator` / `vc-demo` once inside)  
**Repo:** https://github.com/prendleman/vc-retail-analytics

## Short version

Yesterday the demo was a SQLite app with sales analytics for 50 synthetic dealers. Today it is the same app with a full supply-chain domain added (sales org, procurement, inventory, MRP), and the whole thing was built and verified end-to-end on a real Snowflake Enterprise account against Snowflake's shared 10 TB TPC-DS retail dataset. The hosted demo still defaults to SQLite (fast, sub-second), and now has a **SQLite | Snowflake · 10 TB** switch in the header so a reviewer can flip their own session to the live Snowflake build and run the same questions against the 10 TB backbone.

## What shipped today (four commits)

### 1. Supply-chain domain — `87b8db8`

- 14 new tables: salespeople, rep assignments and quotas, vendors and contracts, components, BOM, purchase orders / lines, shipments, receipts, inventory snapshots, demand forecast, MRP plan, work orders.
- 16 new governed metrics behind the deterministic assistant (rep attainment, PO past-due, vendor OTIF scorecard, DC inventory health, forecast accuracy, MRP exceptions, etc.). Same pattern as before: exact-match router → vetted SQL → result + SQL trace. No LLM in the runtime.
- Two new Analytics sections in the UI: **Procurement** and **Planning**.
- Snowflake build scripts (`sql/snowflake/06–08`) that map TPC-DS onto the Visual Comfort shape: stores → dealers, items → products, warehouses → distribution centers, states → territories, plus a generated layer for everything TPC-DS does not have (reps, vendors, BOM, POs, MRP).
- `scripts/cloud.py` gained `backbone` / `generate` / `build` steps, a LARGE build warehouse that auto-suspends, `--confirm-cost`, and `--scale`.

### 2. Live Snowflake build, verified — `6e228a0`

Ran the full chain on a dedicated Snowflake Enterprise account (AWS us-east-1). Results, from `docs/evidence/`:

Calibration work in this commit was about making a general-merchandise retailer look like a lighting dealer: 1-in-200 ticket sampling, quantity rescale, money derived from re-skinned list price × the row's own discount (never TPC-DS dollar columns), rep quotas tuned to ~100% median attainment, vendor OTIF spread 38–95% across Prefer / Watch / Exit tiers, forecast bias within ±12% by family, MRP exceptions landing in all four codes.

### 4. Hosted SQLite ↔ Snowflake toggle — live

A **SQLite | Snowflake · 10 TB** switch in the hosted app header. Per browser session, login required, same governed SQL on both sides; the server proves the target backend answers before switching and refuses if Snowflake is not configured on that host. The Fly box authenticates to Snowflake as a dedicated service user that holds only the reader role, via a role-restricted programmatic access token held as a Fly secret — nothing in the image or repo. Measured on the live host: switch to Snowflake 4.3 s (warehouse resume), portfolio summary 1.6 s (1.65 M SKUs, 1,500 dealers, $1.64 B net), full analytics overview 4.4 s, switch back instant. Suite 8/8 with the new toggle test.

How to see it: log in as `operator`, click **Snowflake · 10 TB** at the top right, watch "Dealers" go from 50 to 1500, then click **SQLite** to come back.

## What is deliberately not claimed

- Synthetic data only. No Visual Comfort production data, credentials, or systems were touched.
- Seasonality in the Snowflake build is TPC-DS's (strong Q3/Q4), not Visual Comfort's.
- Not yet demonstrated on Snowflake: Cortex Analyst (natural-language → SQL) path and Openflow ingestion. Row access policy is shown on two principals (owner + hosted service user), but not yet with a second principal pinned to a single dealer. Each is scoped in `docs/KNOWN_LIMITATIONS.md` and `docs/SNOWFLAKE.md`.
- Snowflake mode is slower than SQLite by design: first switch resumes the warehouse (~4–5 s), analytics pages run a few seconds instead of sub-second, and the warehouse auto-suspends after 60 s idle.
